# Metadata Vocabulary

This document defines the controlled metadata vocabulary used to classify
the literature included in the **Differentiable and Learnable MPC: A Survey**
repository.

## Metadata Structure

Each paper is described according to:

- Primary methodological classification
- Secondary methodological labels
- Learned MPC component
- Learning paradigm
- Learning algorithm
- Learning stage
- Online optimization requirements
- Application domain
- System/platform
- Safety and theoretical guarantees
